06.

Discounts.

Assign a percentage-off code to an influencer. Their followers type the code at checkout to get the discount — or you can share a direct link that auto-fills the code (hit Copy link on any code row). Add the influencer's email if you want the system to auto-send them a branded email with the code + link; leave it blank if you'll just text or DM the code yourself. Every redemption sends you an email so you know which influencer is driving bookings.

Codes can have a term limit (good until a date) and a usage cap (good for the first N people).

These rows are display-only (they don't feed the /book flow), so the Price field is free text — write anything: $1,500, $350 / hr, $4,800+, Included, Cost + 10%. 09.

Invoices.

Build an invoice, hit send, and Stripe emails your client a payment page with a Pay button. They can pay by card, Apple Pay, or bank transfer. Stripe chases unpaid invoices with automatic reminders, and you get an email the moment one is paid.

Use this for shoot balances, quote-based lifestyle and event jobs, extra retouching, or licensing fees.
